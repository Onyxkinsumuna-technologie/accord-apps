Accord - installateurs Windows et Android
1. Envoyez TOUT le contenu de ce dossier (y compris .github et android-res) dans un depot GitHub.
2. Onglet Actions > Build Accord > attendez la coche verte (10 a 15 min).
3. Pour un lien de telechargement permanent : Releases > Create a new release > tag v1.3 > Publish.
   Fichiers obtenus :
   - Accord-Setup.exe     : INSTALLATEUR Windows (assistant d'installation, raccourci Bureau et menu Demarrer)
   - Accord-Portable.exe  : version sans installation (se lance directement)
   - Accord-Android.apk   : application Android (icone et ecran de demarrage Accord)
